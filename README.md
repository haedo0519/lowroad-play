# LOWROAD 테스트 빌드

화면 아래 작업 표시줄 위에 바 형태로 뜨는 방치형 게임의 테스트 빌드입니다.

- **Windows:** [Releases](../../releases)에서 `LOWROAD-0.19.2-windows.zip`을 받아 압축을 풀고 `LOWROAD.exe`를 실행하세요. 설치할 것은 없습니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누르세요(서명 안 된 빌드).
- **Android:** `LOWROAD-0.19.2-android.apk`는 아직 실제 폰에서 확인하지 못한 첫 시험판입니다.

게임 파일의 저작권은 제작자에게 있습니다. 테스트 목적 외의 재배포를 금합니다. 포함된 오픈소스와 에셋의 라이선스는 [LICENSES.txt](LICENSES.txt)를 보세요.
